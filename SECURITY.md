# Security Policy

## Scope

This repository folder is a local mock demo only. It does not contain live integrations, packaging configuration, private data, or infrastructure deployment assets.

## Reporting Issues

Report security issues through the repository owner's preferred private disclosure channel. Do not post exploit details, private values, or sensitive reproduction material in a public issue.

## Safe Contribution Rules

- Use fake data only.
- Keep all demos local by default.
- Do not add real service endpoints, sensitive key material, packaging assets, paid service code, or customer records.
- Keep configuration examples generic and nonfunctional unless they are explicitly local-only.
